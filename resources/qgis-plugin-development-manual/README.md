# Desenvolvimento de Plugins QGIS com Python

Manual em português, do básico ao avançado, por **Jubílio Filiano Maússe**.

O documento utiliza dois plugins reais como estudos de caso:

- [GPX Batch Converter](https://github.com/Jubilio/gpx-batch-converter)
- [GeoClick Capture](https://github.com/Jubilio/qgis-latlon)

A fonte principal está dividida em `manual/parts/`. O workflow `build-qgis-plugin-manual.yml` concatena as partes, gera os diagramas Graphviz e publica PDF, DOCX, pacote-fonte e hashes SHA-256 em `public/downloads/qgis-plugin-development-manual`.

A publicação neste repositório é um espelho provisório. O material será posteriormente transferido para um repositório dedicado.
